## 개인 관련성 및 불확실성

## 작성 규칙 — 모든 위키의 인용 기준

이 규칙은 템플릿 안내이므로 출처 페이지에 복사하지 않습니다.

1. 외부에서 가져온 검증 가능한 주장 바로 뒤에 출처 페이지 링크와 위치를 붙입니다. 출처 페이지에는 제목·저자/기관·연도·직접 URL·확인일·열람 범위를 기록합니다. 실제 확인한 DOI/PMID만 씁니다.
2. 근거가 여러 개면 각각 연결합니다. 문서 끝의 참고문헌 목록만으로 핵심 주장·수치·권고의 인용을 대신하지 않습니다. 검색 결과 페이지나 검색 도구의 답변은 원문 근거가 아닙니다.
3. 논문은 방법·대상·표본·중재/비교·기간·결과를 열람 범위 안에서 기록합니다. 수치는 원문의 단위·비교 기준·불확실성(제공된 신뢰구간 등)을 유지합니다. 초록만 읽었다면 본문 표나 세부 방법을 확인했다고 쓰지 않습니다.
4. 책은 제목·저자·판본·장·쪽을 확인합니다. 사용자 메모만 있으면 메모로 표시합니다. 영상은 제목·채널·URL·게시일(확인 가능 시)·구간과 자막 출처/자동 생성 여부를 표시합니다. 자막으로 시각적 동작까지 확인했다고 쓰지 않습니다. 타임스탬프가 없으면 없다고 적습니다.
5. 검색 요약, 썸네일, 제목만으로 본문을 읽은 것처럼 요약하지 않습니다. 접근 실패 시 `미확인`으로 남기고 확인된 근거의 범위에서 답합니다. 재인용은 원연구를 찾아 검증하거나 `간접 인용`이라고 밝힙니다.
6. 주장별로 연구 근거 / 출처 저자의 설명 / 개인 관찰 / LLM의 적용 추론을 구분합니다. 근거의 확실성은 설계·편향·일관성·정밀도·개인과의 관련성을 근거로 설명하며, 정식 평가 없이 GRADE 등급을 부여하지 않습니다.
7. 교정·철회·업데이트 여부를 가능한 범위에서 확인하고 확인 범위를 기록합니다. 논문 수를 채우려고 관련 없는 출처를 추가하지 않습니다.
8. 개인 진술에는 날짜와 기록 링크를 붙입니다. 원본 없는 채팅 진술은 해당 날짜의 기록에 사용자 진술로 보존합니다. 관찰을 진단이나 인과의 근거로 승격하지 않습니다.
