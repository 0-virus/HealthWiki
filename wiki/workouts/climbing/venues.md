# 클라이밍 지점별 난이도 등록부

홀드 스티커 색상의 난이도 순서를 지점별로 관리하는 단일 파일이다. 정식 등록에는 사용자에게 확인한 지점명·별칭·위치·쉬움 → 어려움 순서·확인일과 출처가 필요하다. 확인 대기 후보는 지점 자동 매칭이나 난이도 비교에 사용하지 않는다. 절차는 [운동 기록 스킬](../../../.agents/skills/workout-log/SKILL.md)을 따른다.

## 확인 완료된 지점

### 서울숲클라이밍 잠실점

- 입력 날짜·관련 기록: [2026-09-20 클라이밍](records/2026-09-20.md).
- 정식 등록명: 서울숲클라이밍 잠실점.
- 확인된 별칭: 서울숲클라이밍 잠실새내점. 사용자가 두 이름이 같은 지점임을 확인.
- 주소: 서울 송파구 백제고분로7길 49. [HOLDAY 출처](../../sources/2026-09-20-서울숲클라이밍-잠실점-HOLDAY.md), 지점명·주소 절. 이 주소로 제시한 지점을 사용자 확인.
- **쉬움 → 어려움**: 빨강 → 주황 → 노랑 → 초록 → 파랑 → 남색 → 보라 → 갈색 → 검정 → 분홍. 빨강이 가장 쉽고 분홍이 가장 어렵다. [HOLDAY 출처](../../sources/2026-09-20-서울숲클라이밍-잠실점-HOLDAY.md), ‘난이도 색상’ 절의 공통표를 제시한 뒤 사용자가 이 지점에도 동일함을 확인.
- 웹 확인일: 2026-09-20. 연결된 인스타그램은 접근 실패로 직접 확인하지 못함.
- 사용자 확인일·적용 기준일: 2026-09-20. 확인 진술은 [당일 운동 기록의 지점 확인 이력](records/2026-09-20.md#지점-확인-이력)에 보존. 이전 시기의 체계는 미확인.
- 등록 상태: 확인 완료.

## 확인 대기 후보

없음.

- 2026-09-20 후속: 사용자가 잠실점과 제시한 전체 색상 순서를 확인하여 정식 등록. ‘서울숲클라이밍 잠실새내점’을 확인된 별칭으로 추가하고 당일 운동에 연결. 기존 미확정 후보의 순서 자체는 변경 없음.
