## 방법·한계·검증

- 2D 무게중심 근사: <모델·분절 질량 비율·대표점 대체·사용 코드/버전>. 실제 3D 중심 투영이나 손발 하중의 실측이 아니다. 연결선은 뼈·힘의 방향을 나타내지 않는다.
- 좌표: 이미지 픽셀, x 오른쪽·y 아래쪽. 카메라 이동: <관찰과 보정 여부>. <변위/속도를 보고할 경우 단위·좌표계·유효 프레임 수·보정 한계>.
- 중심 표시: 현재 프레임의 중심을 노란 점으로 표시. <유효/전체 플레이 프레임 수, 누락·가림 구간>. 검출률은 위치 정확도가 아니다.
- 품질 확인: <원본 해시, 디코딩 프레임 수, PTS·전체 길이·음성 보존 결과>. <직접 비교한 시작·크럭스·종료·가림·타인 등장 구간과 남은 문제>.
- 범위 확인: <1초 행 수·0.1초 행 수, 시작/끝·부분 구간·프레임 없는 창 처리>. 두 표는 같은 시도의 다른 해상도이며 중복 시도로 세지 않는다.
- 저장: 분석 결과와 작업 로그만 추가. 원본·기존 운동 기록·위키 본문은 변경하지 않는다(별도 사용자 요청이 있을 때만 통합).
