# Lint — 위키 정합성과 지식의 빈틈 점검

위키 루트는 이 스킬 폴더의 세 단계 위다. 아래 경로는 루트 기준이다. `AGENTS.md`, `wiki/index.md`, 최근 `wiki/log.md`를 읽는다. 출처 기준은 `templates/source.md`를 따른다.

## 범위 파악

사용자가 지정한 범위가 없으면 `wiki/`의 실제 Markdown 페이지 전체를 점검한다. 원본은 출처 대조에 필요할 때 읽는다. `raw/`, `templates/`, `.agents/`, 앱 설정은 위키 지식 페이지 수나 고립 페이지 판정에 포함하지 않는다.

파일 목록과 링크를 조사한 뒤 페이지 내용을 읽는다. 사용 가능한 파일·텍스트 검색 도구를 쓰며 전용 검색 서버나 검사 프레임워크를 설치하지 않는다. 일부만 읽었다면 검사한 파일·범위와 미검사 범위를 밝힌다. 자동 링크 확인이 의미상의 모순 검토를 대신하지 않는다.

## 구조와 출처

- **파일·링크:** 상대 링크의 기준 경로, 공백 인코딩, 대상 파일과 사용된 제목/블록 앵커가 실제로 존재하는지 확인한다. 목차의 누락·잘못된 분류·오래된 요약을 찾는다. 로그의 과거 사실과 원본은 보존한다.
- **고립·연결:** 실제 인바운드 링크가 없는 페이지를 찾는다. 목차에만 연결된 페이지는 고립과 구분해 주제 간 연결 부족으로 보고한다. 원본·출처·주제·질문·계획 사이에 의미 있는 링크가 빠졌는지 읽고 판단한다.
- **메타데이터·중복:** 페이지 유형별 필수 항목·상태·날짜를 확인한다. 의도적으로 메타데이터가 없는 추가 전용 로그와 템플릿 빈칸을 오류로 보고하지 않는다. DOI/PMID·영상 ID·책 판본/구간으로 중복 후보를 찾되 같은 출처의 다른 구간을 자동 병합하지 않는다.
- **인용:** 핵심 주장·수치·권고의 출처와 원문 위치, 직접 URL·서지·확인일·열람 범위를 확인한다. 초록/메모만 보고 원문 전체를 확인했다고 쓴 경우, 간접 인용을 직접 확인으로 표시한 경우, 개인 관찰을 연구 근거처럼 쓴 경우를 찾는다.
- **반영 상태:** 목적 인터뷰 대기 자료가 주제·프로필·계획에 사실로 통합되었는지, integrated 출처에 목적 근거와 관련 링크가 있는지 확인한다.

## 내용과 개인 기록

- 같은 주장에 대한 페이지 간 결론을 비교한다. 대상·용량/부하·기간·측정 결과 차이를 확인한 뒤 실제 모순인지 판단하고 양쪽 페이지와 출처 위치를 보고한다.
- 새 자료가 대체한 주장, 개정된 지침, 교정·철회 가능성을 확인한다. 발행일이 오래되었다는 이유만으로 폐기하지 않는다. 필요하면 현재 제공된 검색 도구로 출처를 확인하고 검색일·실제 확인 범위를 남긴다. 외부 확인이 불가능하면 `외부 확인 필요`로 기록한다.
- 중요한 개념이 여러 페이지에서 설명 없이 반복되는지, 자료 간 연결이나 반대 근거가 빠졌는지 확인한다. 별도 주제 페이지나 추가 질문이 유용한 이유를 제시하며 빈 페이지를 자동 생성하지 않는다.
- 프로필·계획·대시보드·일별 기록을 대조한다. 확인되지 않은 개인 사실, 초안의 무단 실행 전환, 원본과 다른 검사 수치·단위·참고 범위, 빠진 재평가 조건을 찾는다.
- 수치 요약은 기간·유효 기록 수·계산 근거와 측정 조건을 대조한다. 결측을 0으로 채우거나 관찰 변화만으로 인과를 확정한 경우를 표시한다.

## 수정과 보고

대상이 명확한 끊어진 파일 링크와 목차 누락·분류 오류는 수정하고 다시 확인한다. 판단이 필요한 병합·삭제·의학적 결론 변경·개인 사실 수정은 자동으로 하지 않는다. 근거 없이 오류를 정상처럼 보이게 만들지 않는다. 사용자가 점검/보고만 요청하면 어떤 파일도 수정하지 않는다.

보고에는 검사 범위, 발견 사항, 실제 수정 사항, 남은 검증을 구분한다. 발견 사항은 `우선순위 | 페이지·위치 | 관찰한 문제와 근거 | 다음 조치`로 정리한다. 건강 판단을 왜곡할 수 있는 출처·개인 사실 오류를 우선하고 단순 정리 제안은 뒤에 둔다.

자료가 없으면 내용 검증 불가와 구조 검증 결과를 구분한다. 문제가 없다는 결론도 검사한 범위 안에서만 말한다. 후속 연구 제안은 풀 질문, 필요한 근거 종류, 관련 페이지를 적으며 요청 없이 광범위한 새 조사를 시작하지 않는다.

보고 전용 요청이 아니면 `wiki/log.md`에 `lint` 항목으로 검사 범위·수정 링크·미해결 항목·외부 검증 한계를 덧붙인다. 수정한 페이지의 메타데이터와 실제 링크를 재확인하고 결과를 사용자에게 전달한다.
